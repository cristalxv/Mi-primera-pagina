# Mi pagina web
Este proyecto es una pagina web creada como practica de desarrollo web y control de verciones con Git y GitHub. Su objetivo es aprender a organizar archivos, realizar cambios y guardar el historial del proyecto.

# Tecnologias utilizadas
HTML para estructurar el contenido de la pagina.
CSS para los estilos visuales.
JavaScript para agregar interactividad.
Git para controlar las versiones.
GitHub para alojar el repertorio y publicar la pagina.

# Como ejecutar el proyecto
1. Descragar o clonar este repositorio.
2. Abrir la carpeta Mi-primera-pagina.
3. Abrir el archivo index.html en un navegador web.

No necesitas instalar un servidor para abrir esta pagina estatica.

# Estructura del proyecto
-index.html: contiene la estructura de la pagina.
-css/style.css: contiene los estilo visuales.
-js/script.js:controla la interaccion del boton.
-img/: carpeta destinada a las imagenes.
